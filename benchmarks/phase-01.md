## 共通手順
試験専用データを使う。端末、OS、言語、入力方法、利用画面、設定、ネットワーク、時刻を記録。原則として条件ごとに独立3試行（可能なら新規会話）、試行ごとの成否と時間を保存する。条件変更時は別系列とし、不明なモデルはUNKNOWN。試験用メモの作成・追記のみ行い、削除は別途承認する。公開記録は匿名化する。

| ID | 課題 | 合格条件 |
|---|---|---|
| BM-01 | 合成コードの座標と名前を列挙 | 2件の識別子、座標が全て一致 |

| BM-03 | 固定文の新規メモ作成 | 対象メモが作成され、本文が指定どおり |

| BM-06 | Python等の専門用語の読み上げ | 正式綴りと音声を別記録。日本語で許容する発音を事前定義し評価 |

## BM-01 固定入力（合成データ）
```python
for j, y in enumerate([-37.1, -32.9]):
    name = f"gate.post.{j}"
    x = -191
    print(name, x, y)
```
依頼：「各門柱の名前、x、yを列挙してください。コードから分からない左右の意味は断定しないでください。」
期待値：gate.post.0, -191, -37.1 / gate.post.1, -191, -32.9。

## BM-03～05 固定入力例
新規作成タイトル：SiriAI-Lab TEST（試行IDを末尾に付加）。
本文：ALPHA-01\nBRAVO-02\nCHARLIE-03（実際の入力では改行する）。
追記：DELTA-04。
長文は試験前に別ファイルへ固定し、開始・中間・末尾の識別文字列を含める。全文転記を明示する。BM-05は固定文が準備できるまでNOT_RUN。

## 結果記録の項目
試験ID、試行ID、日時、環境、入力、期待結果、実測出力、処理結果、所要秒数、判定、証拠参照、制約・例外。結果未取得の欄はUNKNOWNとし、NOT_RUNとFAILを混同しない。
集計は成功数/全実施数、欠落数、時間の中央値・範囲を個別に示す。小標本のため性能の一般化はしない。
